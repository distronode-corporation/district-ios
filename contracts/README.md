# Contract fixtures

These JSON files are recorded responses from the District AI API, and they are the
wire-format contract this app is built against. They are generated by the District AI
service's own test suite, which checks its real responses against them byte for byte,
and are copied here unchanged. `ContractFixtureTests` in `Packages/DistrictCore` runs
every fixture that has a Swift model through a strict gate (no `null` outside a reviewed
allow-list, decode, re-encode, and the re-encoded keys must equal the fixture's at every
level) and asserts the exact number of files, so a missing directory or a new fixture
fails the suite instead of passing it silently. Edits are not accepted in this
repository: if a fixture looks wrong, or the app and the service disagree about a
response, open an issue.
